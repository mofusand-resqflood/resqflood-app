\## 1. Project Description



ResQFlood is a mobile-based flood rescue and emergency response application developed to improve communication, coordination and assistance during flood situations.



The application provides a centralised platform that connects residents, emergency responders and shelter administrators to support effective flood emergency management.



Through ResQFlood, residents can report flood incidents and locate nearby evacuation shelters, while responders can manage emergency reports, prioritise cases and coordinate rescue operations. Shelter administrators can manage shelter capacity, monitor check-ins and handle supply requests.



The main objective of ResQFlood is to facilitate faster emergency response, improve information sharing and support better coordination among the different parties involved during flood disasters.



\## 2. User Roles



ResQFlood consists of three main user roles:



\### 2.1 Resident



Residents are individuals affected by floods who need to report incidents and request emergency assistance.



Main functionalities:

\- Register and log in to the application.

\- Submit flood and emergency reports.

\- Upload photographs of flood incidents.

\- Provide location information for emergency reports.

\- Track the status of submitted reports.

\- View nearby evacuation shelters.

\- Access emergency information and assistance.



\### 2.2 Emergency Responder



Emergency responders are responsible for managing reported incidents and coordinating rescue activities.



Main functionalities:

\- View incoming flood and emergency reports.

\- Review and prioritise reported incidents.

\- Manage and assign emergency response tasks.

\- Monitor assigned rescue operations.

\- View flood-affected locations through a map.

\- Update the progress and status of response tasks.

\- Coordinate emergency response activities.



\### 2.3 Shelter Administrator



Shelter administrators are responsible for managing evacuation shelters and monitoring available resources.



Main functionalities:

\- Manage shelter information.

\- Monitor shelter occupancy and available capacity.

\- Handle resident check-ins using QR codes.

\- Monitor available food, water and other supplies.

\- Manage shelter supply requests.

\- Update shelter capacity and resource information.



\## 3. How to Run the Application



\### 3.1 Prerequisites



Before running ResQFlood, ensure that the following tools are installed:



\- Flutter SDK (3.47.9)

\- Dart SDK (3.13.7)

\- Android Studio

\- Android SDK

\- Visual Studio Code or another compatible code editor

\- Git

\- Android Emulator or a physical Android device



\### 3.2 Clone the Repository



Open a terminal and clone the project repository:



```bash

git clone git@github.com:mofusand-resqflood/resqflood-app.git

```



\### 3.3 Navigate to the Project Directory



```bash

cd resqflood-app

```



\### 3.4 Install Dependencies



Download the required Flutter packages:



```bash

flutter pub get

```



\### 3.5 Check the Development Environment



Run Flutter Doctor to verify the development environment:



```bash

flutter doctor

```



\### 3.6 Run the Application



Connect an Android device or start an Android emulator, then execute:



```bash

flutter run

```



\*\*Note:\*\* Firebase configuration and other required project settings must be completed before running features that depend on external services.
